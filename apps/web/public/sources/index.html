แหล่งข้อมูลและเครดิต

รุ่น P0 มีเฉพาะประกาศทางการ ส่วนฝนตรวจวัด พยากรณ์ น้ำท่วม ระดับน้ำ เขื่อน กล้อง และข่าว ยังไม่มีข้อมูลในสัญญาชุดนี้

กรมอุตุนิยมวิทยา — ประกาศ CAP

ข้อมูลจาก CAP feed ของกรมอุตุนิยมวิทยา ผ่านระบบเก็บข้อมูลของ fontokmai ทุก 15 นาที หน้าเว็บแสดงข้อความและขอบเขตตามต้นฉบับ พร้อมลิงก์ของแต่ละประกาศ ไม่ใช่ผลประเมินภัยที่ fontokmai คำนวณเอง

CAP channel นี้ระบุ public domain เรายังคงให้เครดิต “กรมอุตุนิยมวิทยา” ทุกครั้ง ข้อมูลชุดอื่นของกรมอุตุฯ อาจมีเงื่อนไขต่างกัน ดู เว็บไซต์ข้อมูลกรมอุตุฯ

fontokmai ไม่ได้เกี่ยวข้องหรือได้รับการสนับสนุนจากกรมอุตุนิยมวิทยา

แผนที่ฐาน

แสดงด้วย MapLibre GL JS โดยใช้ OpenFreeMap / OpenMapTiles และข้อมูล © OpenStreetMap contributors (ODbL) แผนที่เป็นข้อมูลอ้างอิงตำแหน่ง ไม่ใช่แหล่งพยากรณ์อากาศ หากแผนที่โหลดไม่ได้ให้ใช้มุมมองรายการ

ข้อมูลที่ยังไม่มี

หน้าเว็บไม่ดึงหน้าเว็บ กทม. หรือ ThaiWater โดยตรง ข้อมูลใหม่จะเพิ่มเมื่อมีช่องทางที่ได้รับอนุญาตและสัญญาจาก pipeline เท่านั้น การอ่านเว็บได้โดยไม่ล็อกอินไม่ได้แปลว่าอนุญาตให้นำข้อมูลมาเผยแพร่ต่อ
