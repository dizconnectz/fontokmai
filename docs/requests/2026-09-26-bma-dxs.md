# สมัคร DXS ของสำนักการระบายน้ำ กทม. (ผู้ใช้นัดทำ 2026-09-26)

> Claude เตรียมไว้เมื่อ 2026-09-25 จากหน้าสมัครจริง · ทำตาม D27: ขอข้อมูลเฉพาะผ่านช่องทางที่หน่วยงานเปิดรับจริง
> ผู้ใช้กรอกข้อมูลส่วนตัวและแนบบัตรเอง (agent กรอกเลขบัตรหรือส่งฟอร์มแทนไม่ได้)

## ทำไมต้องสมัคร
- DXS (`dxs.dds.bangkok.go.th`) คือช่องทางทางการที่ กทม. ใช้แจกข้อมูล เปิดตั้งแต่ 2022-08-12 และประชาชนทั่วไปสมัครได้
- ในใบสมัครมีวัตถุประสงค์ **“นำไปให้บริการเผยแพร่ข้อมูลต่อ”** ซึ่งตรงกับเว็บ fontokmai
- เงื่อนไขของ กทม. ห้ามดึงข้อมูลจากหน้าเว็บด้วยโปรแกรม และห้ามเผยแพร่ต่อถ้าไม่ได้รับอนุญาต จึงต้องใช้ข้อมูลผ่าน DXS เท่านั้น

## ขั้นตอน (ราว 10 นาที)
1. เปิด https://dxs.dds.bangkok.go.th/public/register
2. อ่าน “เงื่อนไข ข้อตกลงการใช้บริการ” (สรุปข้อสำคัญอยู่ด้านล่าง) แล้วกดยอมรับถ้าตกลง
3. เลือกประเภทผู้ลงทะเบียน **ประชาชนทั่วไป**
4. กรอกข้อมูล:
   - คำนำหน้า และชื่อ-สกุลทั้งภาษาไทยและภาษาอังกฤษ
   - เลขประจำตัวบัตรประชาชน
   - E-mail ที่เช็กบ่อย เพราะผลอนุมัติจะส่งมาทางนี้
5. อาชีพปัจจุบัน: เลือกตามจริง
6. วัตถุประสงค์: **นำไปให้บริการเผยแพร่ข้อมูลต่อ**
7. แนบรูปถ่ายด้านหน้าบัตรประชาชน (PDF หรือ JPG)
   - แนะนำเขียนทับสำเนาว่า “ใช้สมัคร DXS สำนักการระบายน้ำ เท่านั้น” โดยไม่บังตัวอักษรสำคัญ
8. กดส่ง แล้วรออีเมลตอบรับหรือผลอนุมัติ

## หลังได้อนุมัติ
- เข้าระบบแล้วดูว่าได้บริการใดบ้าง ถ้าต้องเลือกบริการ ให้เลือกเฉพาะที่ใช้:

| บริการ | ใช้ทำอะไร |
|---|---|
| `getFloodingDailyReport`, `getFloodingReportLastUpdate` | รายงานน้ำท่วมขังถนนสายหลักรายวัน สำหรับค้นหาว่าถนนไหนท่วม |
| `GetWaterLastData`, `GetWaterInfo` | ระดับน้ำคลองล่าสุดและรายละเอียดสถานี |
| `GetRainLastData`, `GetRainInfo` | ฝนล่าสุดและรายละเอียดสถานี |
| `getCanalList` | รายชื่อคลอง สำหรับจับคู่ชื่อ |

- บริการที่ไม่ได้ใช้ เช่น ตลาดหรือข่าว ไม่ต้องขอ
- **อย่าส่งรหัสหรือ key ในแชท**: ให้บันทึกลงไฟล์ `C:\Users\User\.fontokmai\dxs_key.txt` (อยู่นอก repo) แล้วบอก Claude
  - Claude จะส่งไฟล์นั้นขึ้น VPS โดยไม่เปิดอ่าน และตั้งสิทธิ์ให้อ่านได้เฉพาะเจ้าของ

## สรุปเงื่อนไขสำคัญ (อ่านจากหน้าสมัคร 2026-09-25)
- ใช้ได้ตามวัตถุประสงค์ที่ได้รับอนุญาตเท่านั้น (ข้อ 3.2)
- ห้ามเข้าถึงด้วยวิธีอื่นหรือใช้สคริปต์นอกช่องทางที่ กทม. จัดให้ ถ้าไม่ได้รับอนุญาตชัดแจ้ง (3.3)
- ห้ามทำสำเนา ทำซ้ำ ขาย แลกเปลี่ยน หรือขายต่อบริการ ถ้าไม่ได้รับอนุญาตชัดแจ้ง (3.5)
  - สิ่งที่เราต้องได้คือการอนุมัติวัตถุประสงค์ “เผยแพร่ต่อ”
- ห้ามใช้ชื่อทางการค้า ตรา หรือโลโก้ของสำนักการระบายน้ำ ถ้าไม่ได้รับอนุญาตเป็นลายลักษณ์อักษร (5.3)
  - เว็บเราให้เครดิตเป็นข้อความว่าเป็นที่มาของข้อมูล ไม่ใช้โลโก้ และไม่ทำให้ดูเหมือน กทม. รับรอง
- การลิงก์เข้าหน้าภายในของเว็บไซต์ DXS ต้องได้รับความยินยอมเป็นหนังสือ (4.2)
  - เราลิงก์ไปหน้าสาธารณะของ กทม. (`dds.bangkok.go.th`, `weather.bangkok.go.th`) และไม่ลิงก์เข้า DXS
- กทม. หยุดหรือยกเลิกบริการได้โดยไม่แจ้งล่วงหน้า (2.5) จึงต้องให้เว็บแสดง “ยังไม่มีข้อมูล” ได้เมื่อข้อมูลหาย
